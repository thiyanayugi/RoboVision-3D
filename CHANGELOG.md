# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-12-01

### Added
- Module 1: Object detection pipeline with YOLOv8
- Module 2: Point cloud colorization from RGB projections
- Module 3: Map alignment using feature-based registration
- Utility scripts for ROS bag extraction and data synchronization
- Comprehensive documentation for each module

### Technical Details
- Multi-sensor fusion (ZED stereo + Livox LiDAR + 2D laser)
- DBSCAN clustering for detection refinement
- ICP-based point cloud registration
- Support for bathroom and office test environments
